# AudioVolume-Rainmeter
AudioVolume —— Rainmeter 扬声器/麦克风电平皮肤，两块卡片实时显示音量。

功能
SPEAKER：大字为该设备当前实际播放电平百分比，下方小字是系统设置音量，右侧电平条随声音实时起伏
MICROPHONE：显示默认录音设备的实时输入电平百分比与电平条

特点
数据取自 Windows Core Audio（WASAPI）峰值表，与系统「声音设置」里的电平条同源，非估算值
深色 / 浅色双主题，左键点 SPEAKER 卡切换，选择会记住

安装：
解压 → 双击 install.bat

要求：
Rainmeter 4.5+ / Windows 10 或 11

说明：
本程序及文档由 AI参与创作完成。
文件中包含一个api密钥监测脚本，有需要可以自提。
